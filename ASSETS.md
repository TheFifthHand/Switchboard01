# Asset provenance — SWITCHBOARD / 01

Every sound in SWITCHBOARD / 01 is generated on the user's device by original code in this
repository. No recorded samples, loops, presets or patterns from third parties are bundled.

| Asset | Source | Licence / permission |
|-------|--------|----------------------|
| Drum kits (5 kits × 16 voices) | Synthesized at runtime by `src/audio/instruments/drumSynth.ts` from recipes in `src/audio/instruments/kits.ts` | Original work of this project |
| Built-in samples (Glass Chord, Tape Swell, Bell Hit, Noise Riser, Vocal "Oh") | Synthesized at runtime by `src/audio/instruments/builtinSamples.ts` | Original work of this project |
| Synth presets (18) | Parameter values in `src/content/presets.ts` | Original work of this project |
| Starter projects (8 + blank) — all patterns, chord progressions and melodies | `src/content/starters/` | Original work of this project |
| Reverb impulse responses | Generated at runtime (seeded noise) by `src/audio/modules/fxutil.ts` | Original work of this project |
| App icons (`public/icons/`) | Generated by `scripts/make-icons.mjs` | Original work of this project |
| Inter (variable) font | `@fontsource-variable/inter` npm package, bundled with the build | SIL Open Font License 1.1 (redistribution permitted) |
| IBM Plex Mono font | `@fontsource/ibm-plex-mono` npm package, bundled with the build | SIL Open Font License 1.1 (redistribution permitted) |

Runtime JavaScript dependencies (bundled into the build, MIT licensed): React, React DOM, Immer,
fflate, idb, workbox-window (service worker helpers generated by vite-plugin-pwa / Workbox, MIT).

User-imported audio stays on the user's device (IndexedDB and exported project bundles). It is
never uploaded and is not part of this repository.
